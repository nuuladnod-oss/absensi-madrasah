Matikan Konversi Otomatis Git (Paling Direkomendasikan)Agar peringatan LF/CRLF ini hilang selamanya dan tidak mengganggu proses commit, Anda bisa mengatur Git agar menerima format apa adanya.Buka VS Code, lalu buka terminal (tekan Ctrl + ~ atau klik Terminal > New Terminal), kemudian ketik perintah berikut dan tekan Enter:bashgit config --global autocrlf false
